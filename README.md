# eugenehernandez.github.io

Source for my personal site at https://eugenehernandez.github.io/, a landing page that links to my data science projects.

* `index.html` is the page itself.
* `sitemap.xml` lists the pages for search engines, including the project sites under this address.
* `robots.txt` points search engines to the sitemap.
* The `google....html` file verifies ownership for Google Search Console. Keep it in the repository.

Changes go live a minute or two after they are committed to the `main` branch.
